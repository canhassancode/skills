# grilling (deprecated)

Superseded by [`align`](../../engineering/align/SKILL.md). The interview loop survives intact — one question at a time, facts looked up rather than asked, decisions kept with the operator — but it now runs against named **Scenarios**, carries a recommendation and a plain-English reason per question, and leaves an **Alignment artefact** rather than shared understanding.

The failure this skill earned its retirement on: an interview with no target produces agreement that cannot be written down. Resolving a decision tree in the abstract never asks what the interface is, what the sequence does, or whether the domain model has a word for this.

Run `/align` instead.
