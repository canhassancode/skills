# Morning Brief (deprecated)

Retired rather than superseded. `morning-brief` compiled `~/Obsidian/Journal/<YYYY-MM-DD>-brief.md`, the opening file of a three-file daily Operating Loop (brief → log → summary). The Loop and its `Journal/` directory are gone: the vault narrowed to the two subsystems it was designed as — a Library for the world and a Profile for Hassan — and cross-day continuity is not one of them.

Nothing replaces it. Open work lives on the issue tracker.
