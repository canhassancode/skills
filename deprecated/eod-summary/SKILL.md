# EOD Summary (deprecated)

Retired rather than superseded. `eod-summary` wrote `~/Obsidian/Journal/<YYYY-MM-DD>-summary.md`, the closing file of a three-file daily Operating Loop (brief → log → summary), consolidating the day's log into a carry-forward signal. The Loop and its `Journal/` directory are gone; the vault no longer carries a daily record for a summary to consolidate.

Nothing replaces it. Carry-forward lives on the issue tracker.
