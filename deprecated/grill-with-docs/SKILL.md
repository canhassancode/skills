# grill-with-docs (deprecated)

Superseded by [`align`](../../engineering/align/SKILL.md).

The **four-pass discipline** it owned — trace request paths rather than listing modules, grep for consumers, sketch `CONTEXT.md` if missing, check for feature flags and branches that hide parallel surfaces — is now `/align`'s step 2, and [the skill](../../engineering/align/SKILL.md) defines it.

Its **authority order** — the repo's `CONTEXT.md` and ADRs are canon, the vault is supplementary and any vault page contradicting live code is a flag rather than a fact — survives as `/align`'s sourcing rule: every claim carries where it came from, and the model itself is reconciled by `/domain-modeling` rather than restated inline.

Its **close-routing table** (sending a session to `/to-spec`, `/to-proposal` or tickets) has no successor yet. `/align` closes with a **Verdict** and hands the artefact on; whatever publishes it is stage 2, which is not yet designed.

Run `/align` instead.
